# Customer-Churn-Analysis-Project---Telecom-Sector
Analyze customer churn patterns in a telecom company, identify key drivers of churn, and provide data-driven recommendations to reduce customer attrition.
## Overview
This project involves analyzing customer churn for a telecom company using Excel. The goal is to explore churn rates, identify reasons for churn, and provide insights to help reduce customer loss. The dataset includes customer demographics, contract details, subscription types, and usage data.
## Features
- **Exploratory Data Analysis (EDA)**: Cleaning and preparing data for analysis.
- **Churn Calculation**: Creating a churn metric to analyze customer loss.
- **Churn Reason Analysis**: Identifying the most common reasons for churn using visualizations.
- **Demographic Analysis**: Exploring customer age, contract type, and usage trends.
- **Dashboard Creation**: Building an interactive Excel dashboard with KPIs and insights.
## Dataset
The dataset consists of two worksheets:
- **Databel - Aggregate**: Summary-level statistics.
- **Databel - Customer**: Detailed customer-level data.

- **Churn _Analysis0
## Key Analysis Steps
1. **Data Preparation**: Checking for duplicates and structuring data in table format.
2. **Churn Rate Calculation**: Converting churn labels into a numerical format for analysis.
3. **Churn Reasons**: Visualizing reasons and categories leading to customer churn.
4. **Demographic Segmentation**: Grouping customers by age, contract type, and subscription plans.
5. **Consumption Insights**: Analyzing usage patterns and service plans.
6. **KPI Dashboard**: Summarizing key metrics, churn trends, and customer profiles.
